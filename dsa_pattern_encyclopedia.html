👆 Two Pointers ▼
Use two indices to traverse an array efficiently, often in a sorted array. Great for finding pairs or rearranging data.
Sorted array Easy start
When to use
  • Finding a pair that sums to target
  • Removing duplicates from sorted array
  • Reversing an array
  • Container with most water
Why it works

One pointer starts at beginning, one at end. Move inward based on logic. Avoids nested loops.

Time complexity
O(n)
Space complexity
O(1)
Prerequisite
Sorted or specific structure
📦 Sliding Window ▼
Keep a "window" of elements and slide it across the array. Perfect for finding optimal contiguous subarrays.
Contiguous subarrays Easy start
When to use
  • Max/min sum of k elements
  • Longest substring without repeating chars
  • Best time to buy and sell stock
  • Permutation in string
The idea

Expand window by moving right pointer. Shrink by moving left pointer. Calculate result at each step.

Time complexity
O(n)
Space complexity
O(1) to O(k)
Pattern type
Dynamic sizing
🎯 Hash Map / Set ▼
Store data in key-value pairs or unique sets. Super fast lookups and frequency tracking.
Fast lookup Easy start
When to use
  • Detect duplicates in array
  • Count frequency of elements
  • Check if two strings are anagrams
  • Find missing number in array
The trick

Trade space for time. Store what you've seen. On second encounter, you know it's a duplicate or match.

Time complexity
O(n)
Space complexity
O(n)
Best for
Lookups
🔍 Binary Search ▼
Divide and conquer on sorted data. Jump straight to half the space each time.
Sorted array Most common
When to use
  • Find target in sorted array
  • Search rotated sorted array
  • Find first/last position of element
  • Search insert position
The logic

Set left and right pointers. Calc mid. Compare target with mid. Move left or right. Repeat until found.

Time complexity
O(log n)
Space complexity
O(1)
Requirement
Sorted input
📚 Stack / Queue (LIFO / FIFO) ▼
Use last-in-first-out or first-in-first-out ordering to solve problems involving order and depth.
Order matters Most common
Stack problems (LIFO)
  • Valid parentheses matching
  • Undo/Redo functionality
  • Depth-first search
  • Decode string
Queue problems (FIFO)
  • Breadth-first search
  • Level-order tree traversal
  • Task scheduling
Push/Pop
O(1)
Space
O(n)
🌳 DFS / BFS (Graph Traversal) ▼
Systematically explore graphs or trees. DFS goes deep, BFS goes wide.
Tree/Graph Most common
DFS use cases
  • Connected components count
  • Path finding
  • Tree inorder/preorder traversal
  • Topological sort
BFS use cases
  • Shortest path (unweighted)
  • Level-order traversal
  • Word ladder
Time
O(V + E)
Space
O(V)
💭 Dynamic Programming ▼
Break problem into overlapping subproblems. Solve once, store, and reuse results.
Overlapping subproblems Advanced
When to use
  • Fibonacci sequence
  • Coin change (min coins)
  • Longest increasing subsequence
  • Knapsack problem
  • Edit distance (Levenshtein)
Two approaches

Top-down (Memoization): Recursion with caching. Bottom-up (Tabulation): Build table from base cases.

Time
Problem-specific
Space
O(n) to O(n²)
⚡ Greedy Algorithm ▼
Make locally optimal choice at each step, hoping it leads to global optimum.
Local → Global Advanced
When it works
  • Activity selection problem
  • Huffman coding
  • Jump game (reach end)
  • Gas station (can complete loop)
The catch

Doesn't always work! Prove it works for your specific problem before using it.

Advantage
Fast & simple
Disadvantage
Not always optimal
